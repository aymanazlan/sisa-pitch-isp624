# SISA: WasteHotspot AI – ISP624 Innovation Pitch (Group EcoSpark)

Interactive web pitch deck for the ISP624 group project pitching (10-minute limit).

**Live deck:** https://aymanazlan.github.io/sisa-pitch-isp624/
**Live 3D version (waste-township theme):** https://aymanazlan.github.io/sisa-pitch-isp624/live/
**Clean-up sweep version (litter is swept into a garbage truck on every slide):** https://aymanazlan.github.io/sisa-pitch-isp624/sweep/
**Speaker script and Q&A:** https://aymanazlan.github.io/sisa-pitch-isp624/script.html

Controls: ← → or swipe to change slides · N for speaker notes · T to start or pause the timer (Shift+T resets) · F for full screen · W turns the 3D world off or on (use it if a slow laptop lags).
The deck is a single offline `index.html` (images, video and the three.js 3D engine embedded; only the web fonts load online). Behind every slide, one 3D world of about 1,000 glowing “waste reports” rebuilds itself into a new shape: scattered rubbish, the SISA leaf, an endless loop with residents walking past, a heap, two users, a township map, one merging hotspot beam, a phone and rising bars.

Demo video: https://youtu.be/X-V6bfDxrZM · Prototype code: https://github.com/ariefnajib25/WasteHotspot-AI
